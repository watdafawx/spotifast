Spotifast 0.17.2 (mods) picks the AI model for lyrics translation from the provider's own list, falls back to other models when one fails, and finds genres for more artists.

## New

- **Pick the translation model from a list.** With an API key saved, the Model field becomes a dropdown fetched from Gemini or your OpenAI-compatible provider, with a Refresh button.
- **Show only free models.** OpenRouter marks which models cost nothing; one switch limits the list to them, and Spotifast remembers it.
- **Fall back to other models.** When a request fails, Spotifast tries up to four other free models from the list, then the other provider if its key is saved. It is on by default and has its own switch; your lyrics go to each one tried.

## Fixed

- **Genres for more artists.** When MusicBrainz has none, the player bar now asks Wikidata by the artist's Spotify ID, then searches MusicBrainz by name (only for one exact match) before using Last.fm.
- **Clearer errors when a model list can't be fetched.** The message now says why (DNS, TLS, refused) instead of only "error sending request".
